## Choosing for each application
Match the posting's actual responsibilities, not just the company's industry. Record the exact file you uploaded and a one-line reason in the Agent Queue row.

## Making a better-fitting version
If no resume fits well, start from the closest one and keep its format. Reorder, condense and reword what's already on the master resume. Never add metrics, skills, or experience that aren't on the master. Keep it to one page. Save the new version separately and record exactly which file was submitted.
